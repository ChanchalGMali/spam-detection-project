# Spam Detection Website Using Django and Machine Learning

## 📌 Project Description
This project is a web-based spam detection system built using:
- Django
- Machine Learning
- Python
- CSV dataset

## 🚀 Features
- Detect spam emails
- Machine learning model integration
- Web interface using Django

## 🛠️ How to Run
1. Clone the repository
2. Create virtual environment
3. Install requirements
4. Run:
   python manage.py runserver
